# SDG Alignment

DataPulse aligns with Sustainable Development Goal 16, particularly Target 16.6, which calls for effective, accountable and transparent institutions. At the university-department level, DataPulse supports this aim by validating institutional datasets, displaying data-quality results, and keeping an audit trail of issues and their resolution. The project will track the number of datasets assessed, validation issues resolved, and median resolution time. These are project-level measures of contribution, not official UN SDG indicators.

Reference: [United Nations SDG 16, including Target 16.6](https://sdgs.un.org/goals/goal16).
