## 1. Problem Statement & Domain Overview

University academic and administrative departments routinely exchange tabular datasets containing student demographics, examination marks, course attendance, and fee payments. However, manual checks frequently overlook missing identifiers, duplicate records, malformed email addresses, and out-of-range numerical metrics until late in semester processing.

**DataPulse** provides an institutional, auditable data-quality assurance platform. Analysts can define dataset schemas, configure multi-type validation rules (`REQUIRED`, `UNIQUE`, `EMAIL`, `RANGE`, `TYPE`), upload CSV files, automatically generate detailed quality issues, execute automated quality scoring algorithms, and maintain a verifiable audit trail of issue resolutions.

### Sustainable Development Goal Alignment
DataPulse directly supports **UN Sustainable Development Goal 16 (Target 16.6)**: *â€œDevelop effective, accountable, and transparent institutions at all levels.â€* by guaranteeing data integrity, automated audit logging, and transparent data quality metrics.

## 4. Database Architecture & Design (3NF)

The database schema is defined in [`clouddatabase/schema.sql`](clouddatabase/schema.sql) and modeled via Prisma in [`clouddatabase/prisma/schema.prisma`](clouddatabase/prisma/schema.prisma).

### Mandatory Relational Entities (10 Tables)
1. `roles`: Role definitions (`ADMIN`, `ANALYST`) with unique constraints.
2. `users`: Single unified account table with `role_id` foreign key, BCrypt password hash, and unique lowercased email.
3. `datasets`: Institutional dataset registry with unique owner-dataset constraint and lifecycle status.
4. `dataset_fields`: Column specifications with data type checks (`TEXT`, `INTEGER`, `DECIMAL`, `DATE`, `BOOLEAN`).
5. `validation_rules`: Validation rules per field (`REQUIRED`, `UNIQUE`, `EMAIL`, `RANGE`, `TYPE`) with JSONB configuration.
6. `validation_runs`: Execution logs tracking CSV uploads, total row counts, and error counts.
7. `quality_issues`: Granular issue occurrences with row numbers, severity levels (`LOW`, `MEDIUM`, `HIGH`), and status.
8. `issue_resolutions`: Audited resolutions tracking user actions (`FIXED`, `WAIVED`, `REOPENED`) and notes.
9. `quality_scores`: Stored procedure output recording completeness, validity, uniqueness, and overall score (0â€“100).
10. `audit_logs`: Automatic audit log capturing entity mutations, old/new JSON snapshots, and actor IDs.

### Advanced Database Objects
- **Database View**: `dataset_quality_summary` joins datasets with lateral subqueries to compute latest overall quality scores and real-time open issue counts.
- **Stored Procedure**: `recalculate_quality_score(p_run_id)` calculates normalized mathematical dimensions:
  $$\text{Completeness} = 100 \times \frac{\text{Cells} - \text{Missing}}{\text{Cells}}$$
  $$\text{Validity} = 100 \times \frac{\text{Cells} - \text{Invalid}}{\text{Cells}}$$
  $$\text{Uniqueness} = 100 \times \frac{\text{Cells} - \text{Duplicates}}{\text{Cells}}$$
  $$\text{Overall Score} = \frac{\text{Completeness} + \text{Validity} + \text{Uniqueness}}{3}$$
- **Database Trigger**: `trg_audit_quality_issue_change` automatically records all issue insertions and status transitions into `audit_logs`.
- **Database Transactions**: Transactional rollback guarantees atomic execution of CSV validation runs, issue insertions, score computation, and audit logging.

## 5. Quick Start & Execution Steps

### Prerequisites
- Node.js 22.x+ and npm 10.x+
- *(Optional for Spring Boot)*: Java 21 JDK and Maven 3.8+
- *(Optional for Docker)*: Docker Desktop with Docker Compose

---

### Method A: Unified Node.js Full-Stack (Recommended for Instant Evaluation & Vercel)

This mode runs the Express API with embedded 3NF relational engine / Cloud PostgreSQL and serves the React frontend:

1. **Install dependencies**:
   ```powershell
   npm install
   npm run build
   ```

2. **Run Automated Test Suite (10/10 Tests)**:
   ```powershell
   npm test
   ```

3. **Start the API Server**:
   ```powershell
   npm start
   ```
   The backend API will start on `http://localhost:8080`.

4. **In a separate terminal, launch the Frontend (Vite Dev Server)**:
   ```powershell
   npm run dev:frontend
   ```
   Open `http://localhost:5173` in your browser.

---

### Method B: Docker Compose Multi-Container Stack

Runs PostgreSQL 18, Spring Boot 3.5 API, and Nginx-hosted React frontend:

1. **Configure Environment Variables**:
   ```powershell
   Copy-Item .env.example .env
   # Edit .env and supply your local passwords
   ```

2. **Launch Stack**:
   ```powershell
   docker compose up --build
   ```
   - Frontend UI: `http://localhost:5173`
   - Backend API: `http://localhost:8080/api/health`
   - PostgreSQL Database: `localhost:5432`

---

### Method C: Spring Boot Standalone (Java 21)

1. Start a local PostgreSQL server and apply [`clouddatabase/schema.sql`](clouddatabase/schema.sql).
2. Navigate to `backend/spring-boot`:
   ```powershell
   cd backend/spring-boot
   mvn spring-boot:run
   ```

## 7. Native Database Backup & Recovery Guide

Per Section 8 of the assessment brief, native backup and restoration are executed using `pg_dump` and `pg_restore`:

### Using PowerShell (Windows)
```powershell
# Create Native Compressed Dump (.dump)
.\clouddatabase\backup.ps1 -User datapulse -Database datapulse -OutputDir ./backups

# Restore Dump into Fresh Database
.\clouddatabase\restore.ps1 -BackupFile ./backups/datapulse_backup_YYYYMMDD_HHMMSS.dump -TargetDatabase datapulse_restore
```

### Using Bash (Linux/macOS)
```bash
chmod +x ./clouddatabase/backup.sh ./clouddatabase/restore.sh

# Run Backup
./clouddatabase/backup.sh

# Run Restore
./clouddatabase/restore.sh ./backups/datapulse_backup_YYYYMMDD_HHMMSS.dump datapulse_restore
```

-- DataPulse PostgreSQL schema. Run in a new project database.
-- The backend should use JPA/Hibernate for ordinary data access. This SQL file
-- defines the advanced database objects required by the assessment.

BEGIN;

CREATE TABLE roles (
    role_id       bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    role_name     varchar(30) NOT NULL UNIQUE,
    description   text,
    CONSTRAINT ck_roles_role_name CHECK (role_name IN ('ADMIN', 'ANALYST'))
);

CREATE TABLE users (
    user_id       bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    role_id       bigint NOT NULL REFERENCES roles(role_id) ON DELETE RESTRICT,
    full_name     varchar(120) NOT NULL,
    email         varchar(254) NOT NULL,
    password_hash varchar(255) NOT NULL,
    is_active     boolean NOT NULL DEFAULT true,
    created_at    timestamptz NOT NULL DEFAULT now(),
    updated_at    timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT ck_users_email_nonempty CHECK (length(trim(email)) > 0),
    CONSTRAINT ck_users_full_name_nonempty CHECK (length(trim(full_name)) > 0)
);
CREATE UNIQUE INDEX ux_users_email_lower ON users (lower(email));

CREATE TABLE datasets (
    dataset_id   bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    owner_id     bigint NOT NULL REFERENCES users(user_id) ON DELETE RESTRICT,
    dataset_name varchar(160) NOT NULL,
    description  text,
    status       varchar(20) NOT NULL DEFAULT 'ACTIVE',
    created_at   timestamptz NOT NULL DEFAULT now(),
    updated_at   timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT uq_datasets_owner_name UNIQUE (owner_id, dataset_name),
    CONSTRAINT ck_datasets_status CHECK (status IN ('ACTIVE', 'ARCHIVED')),
    CONSTRAINT ck_datasets_name_nonempty CHECK (length(trim(dataset_name)) > 0)
);

CREATE TABLE dataset_fields (
    field_id    bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    dataset_id  bigint NOT NULL REFERENCES datasets(dataset_id) ON DELETE CASCADE,
    field_name  varchar(120) NOT NULL,
    data_type   varchar(20) NOT NULL DEFAULT 'TEXT',
    is_active   boolean NOT NULL DEFAULT true,
    created_at  timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT uq_dataset_fields_dataset_name UNIQUE (dataset_id, field_name),
    CONSTRAINT ck_dataset_fields_data_type
        CHECK (data_type IN ('TEXT', 'INTEGER', 'DECIMAL', 'DATE', 'BOOLEAN')),
    CONSTRAINT ck_dataset_fields_name_nonempty CHECK (length(trim(field_name)) > 0)
);

CREATE TABLE validation_rules (
    rule_id     bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    field_id    bigint NOT NULL REFERENCES dataset_fields(field_id) ON DELETE RESTRICT,
    rule_type   varchar(20) NOT NULL,
    severity    varchar(10) NOT NULL DEFAULT 'MEDIUM',
    rule_config jsonb NOT NULL DEFAULT '{}'::jsonb,
    is_active   boolean NOT NULL DEFAULT true,
    created_at  timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT ck_validation_rules_type
        CHECK (rule_type IN ('REQUIRED', 'UNIQUE', 'EMAIL', 'RANGE', 'TYPE')),
    CONSTRAINT ck_validation_rules_severity
        CHECK (severity IN ('LOW', 'MEDIUM', 'HIGH')),
    CONSTRAINT ck_validation_rules_config_object
        CHECK (jsonb_typeof(rule_config) = 'object')
);

CREATE TABLE validation_runs (
    run_id          bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    dataset_id      bigint NOT NULL REFERENCES datasets(dataset_id) ON DELETE RESTRICT,

-- Summary view used by the dashboard: one latest completed score and current
-- open-issue count per dataset.
CREATE VIEW dataset_quality_summary AS
SELECT
    d.dataset_id,
    d.dataset_name,
    d.status AS dataset_status,
    latest.run_id AS latest_run_id,
    latest.overall_score AS latest_overall_score,
    COALESCE(open_issues.open_issue_count, 0)::bigint AS open_issue_count
FROM datasets AS d
LEFT JOIN LATERAL (
    SELECT vr.run_id, qs.overall_score
    FROM validation_runs AS vr
    JOIN quality_scores AS qs ON qs.run_id = vr.run_id
    WHERE vr.dataset_id = d.dataset_id AND vr.status = 'COMPLETED'
    ORDER BY vr.completed_at DESC, vr.run_id DESC
    LIMIT 1
) AS latest ON true
LEFT JOIN LATERAL (
    SELECT count(*) AS open_issue_count
    FROM quality_issues AS qi
    JOIN validation_runs AS vr ON vr.run_id = qi.run_id
    WHERE vr.dataset_id = d.dataset_id AND qi.status = 'OPEN'
) AS open_issues ON true;

-- Score procedure. The application must call this inside the same transaction
-- that finalizes the run and writes its issues.
CREATE PROCEDURE recalculate_quality_score(IN p_run_id bigint)
LANGUAGE plpgsql
AS $$
DECLARE
    v_dataset_id       bigint;
    v_total_rows       bigint;
    v_field_count      bigint;
    v_total_cells      bigint;
    v_missing_cells    bigint;
    v_duplicate_cells  bigint;
    v_invalid_cells    bigint;
    v_completeness     numeric(5,2);
    v_validity         numeric(5,2);
    v_uniqueness       numeric(5,2);
    v_overall          numeric(5,2);
BEGIN
    SELECT dataset_id, total_rows
      INTO v_dataset_id, v_total_rows
      FROM validation_runs
     WHERE run_id = p_run_id;

    IF NOT FOUND THEN
        RAISE EXCEPTION 'Validation run % does not exist', p_run_id;
    END IF;

    SELECT count(*) INTO v_field_count
      FROM dataset_fields
     WHERE dataset_id = v_dataset_id AND is_active = true;

    v_total_cells := v_total_rows * v_field_count;

    SELECT count(DISTINCT (qi.row_number, vr.field_id))
      INTO v_missing_cells
      FROM quality_issues AS qi
      JOIN validation_rules AS vr ON vr.rule_id = qi.rule_id
     WHERE qi.run_id = p_run_id AND vr.rule_type = 'REQUIRED';

    SELECT count(DISTINCT (qi.row_number, vr.field_id))
      INTO v_duplicate_cells
      FROM quality_issues AS qi
      JOIN validation_rules AS vr ON vr.rule_id = qi.rule_id
     WHERE qi.run_id = p_run_id AND vr.rule_type = 'UNIQUE';

    SELECT count(DISTINCT (qi.row_number, vr.field_id))
      INTO v_invalid_cells
      FROM quality_issues AS qi
      JOIN validation_rules AS vr ON vr.rule_id = qi.rule_id
     WHERE qi.run_id = p_run_id;

    IF v_total_cells = 0 THEN
        v_completeness := 0;
        v_validity := 0;
        v_uniqueness := 0;
    ELSE
        v_completeness := round(100.0 * (v_total_cells - LEAST(v_missing_cells, v_total_cells)) / v_total_cells, 2);
        v_validity := round(100.0 * (v_total_cells - LEAST(v_invalid_cells, v_total_cells)) / v_total_cells, 2);
        v_uniqueness := round(100.0 * (v_total_cells - LEAST(v_duplicate_cells, v_total_cells)) / v_total_cells, 2);
    END IF;

    v_overall := round((v_completeness + v_validity + v_uniqueness) / 3.0, 2);

    INSERT INTO quality_scores (
        run_id, completeness_score, validity_score, uniqueness_score, overall_score, calculated_at
    ) VALUES (
        p_run_id, v_completeness, v_validity, v_uniqueness, v_overall, now()
    )
    ON CONFLICT (run_id) DO UPDATE SET
        completeness_score = EXCLUDED.completeness_score,
        validity_score = EXCLUDED.validity_score,
        uniqueness_score = EXCLUDED.uniqueness_score,
        overall_score = EXCLUDED.overall_score,
        calculated_at = EXCLUDED.calculated_at;
END;
$$;

-- Audit issue creation and status transitions. The backend may set a transaction
-- local value with: SET LOCAL app.user_id = '<authenticated user ID>'.
CREATE FUNCTION audit_quality_issue_change()
RETURNS trigger
LANGUAGE plpgsql
AS $$
DECLARE
    v_actor_user_id bigint;
BEGIN
    v_actor_user_id := NULLIF(current_setting('app.user_id', true), '')::bigint;

    IF TG_OP = 'INSERT' THEN
        INSERT INTO audit_logs (
            actor_user_id, entity_type, entity_id, action, old_values, new_values
        ) VALUES (
            v_actor_user_id, 'QUALITY_ISSUE', NEW.issue_id, 'ISSUE_CREATED', NULL,
            jsonb_build_object('status', NEW.status, 'run_id', NEW.run_id, 'rule_id', NEW.rule_id)
        );
    ELSIF OLD.status IS DISTINCT FROM NEW.status THEN
        INSERT INTO audit_logs (
            actor_user_id, entity_type, entity_id, action, old_values, new_values
        ) VALUES (
            v_actor_user_id, 'QUALITY_ISSUE', NEW.issue_id, 'ISSUE_STATUS_CHANGED',
            jsonb_build_object('status', OLD.status), jsonb_build_object('status', NEW.status)
        );
    END IF;

    RETURN NEW;
END;
$$;

CREATE TRIGGER trg_audit_quality_issue_change
AFTER INSERT OR UPDATE ON quality_issues
FOR EACH ROW
EXECUTE FUNCTION audit_quality_issue_change();

router.post('/datasets/:datasetId/runs', requireAuth, upload.single('file'), async (req, res) => {
  try {
    if (!req.file) {
      return res.status(400).json({ message: 'Choose a CSV file to run validation.' });
    }

    const dataset = await db.getDatasetById(req.params.datasetId, req.user.userId, req.user.role);
    if (!dataset) return res.status(404).json({ message: 'Dataset not found.' });
    if (dataset.status !== 'ACTIVE') {
      return res.status(400).json({ message: 'Archived datasets cannot start new validation runs.' });
    }

    const activeFields = dataset.fields;
    if (activeFields.length === 0) {
      return res.status(400).json({ message: 'Add at least one dataset field before running validation.' });
    }

    const activeRules = [];
    for (const f of activeFields) {
      for (const r of f.rules) {
        if (r.isActive) activeRules.push(r);
      }
    }

    if (activeRules.length === 0) {
      return res.status(400).json({ message: 'Add at least one active validation rule before running validation.' });
    }

    // Run CSV Validation Engine
    const { totalRows, foundIssues } = validateCsvBuffer({
      csvBuffer: req.file.buffer,
      datasetFields: activeFields.map((f) => ({ field_id: f.fieldId, field_name: f.fieldName, data_type: f.dataType })),
      activeRules: activeRules.map((r) => ({
        rule_id: r.ruleId,
        field_id: r.fieldId,
        rule_type: r.ruleType,
        severity: r.severity,
        rule_config: r.ruleConfig,
      })),
    });

    // Execute Transaction: save run, issues, trigger audit, and execute stored procedure recalculate_quality_score
    const runResult = await db.createValidationRunTransaction({
      datasetId: dataset.datasetId,
      userId: req.user.userId,
      totalRows,
      foundIssues,
    });

    res.status(201).json(runResult);
  } catch (err) {
    res.status(err.status || 400).json({ message: err.message });
  }
});

  },

    const user = store.users.find((u) => u.user_id === Number(userId));

    const role = store.roles.find((r) => r.role_id === user.role_id);
    return { ...user, role_name: role ? role.role_name : 'ANALYST' };

  getDatasets: async ({ userId, role, search, status }) => {
    let list = store.datasets.slice();
    if (role !== 'ADMIN') {
      list = list.filter((d) => d.owner_id === Number(userId));
    }
    if (status) {
      list = list.filter((d) => d.status.toUpperCase() === status.toUpperCase());
    }
    if (search) {
      const q = search.toLowerCase();
      list = list.filter((d) => d.dataset_name.toLowerCase().includes(q) || (d.description && d.description.toLowerCase().includes(q)));
    }

    return list.map((d) => {

      const activeFields = store.dataset_fields.filter((f) => f.dataset_id === d.dataset_id && f.is_active);
      const activeRules = store.validation_rules.filter((r) =>
        activeFields.some((f) => f.field_id === r.field_id) && r.is_active
      );

      // Latest completed run & score
      const runs = store.validation_runs

// Middleware: Require Authenticated User
export function requireAuth(req, res, next) {
  const authHeader = req.headers.authorization;
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ message: 'Authentication required. Missing Bearer token.' });
  }

  const token = authHeader.split(' ')[1];
  const decoded = authService.verifyToken(token);
  if (!decoded) {
    return res.status(401).json({ message: 'Invalid or expired token.' });
  }

  req.user = decoded;
  next();
}

// Middleware: Require ADMIN role
export function requireAdmin(req, res, next) {
  if (!req.user || req.user.role !== 'ADMIN') {
    return res.status(403).json({ message: 'Access forbidden: Administrator privileges required.' });
  }
  next();
}

/**
 * DataPulse CSV Validation Engine
 * Authors: Udiksha Agarwal (24BAI0086), Bakya (24BAI0071), Rudra (24BKT0125)
 * Course: BCSE302P Database Systems Lab | Slot: L25+L26
 *
 * Implements:
 * - Streaming / in-memory CSV parser
 * - Rule evaluation: REQUIRED, UNIQUE, EMAIL, RANGE, TYPE
 * - Max file size 5MB, Max rows 5000
 * - Produces quality issues with exact row numbers and observed values
 */

import { parse } from 'csv-parse/sync';

const EMAIL_REGEX = /^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i;
const MAX_ROWS = 5000;

export function validateCsvBuffer({ csvBuffer, datasetFields, activeRules }) {
  if (!csvBuffer || csvBuffer.length === 0) {
    throw new Error('Choose a CSV file to run validation.');
  }

  let records;
  try {
    records = parse(csvBuffer, {
      columns: true,
      skip_empty_lines: true,
      trim: true,
    });
  } catch (err) {
    throw new Error('Could not read the CSV. Check that it has one header row and valid CSV formatting.');
  }

  if (!records || records.length === 0) {
    throw new Error('CSV file is empty or contains only headers.');
  }

  if (records.length > MAX_ROWS) {
    throw new Error(`CSV files are limited to ${MAX_ROWS} data rows for this project demo.`);
  }

  // Check header columns
  const firstRow = records[0];
  const presentHeaders = Object.keys(firstRow).map((h) => h.toLowerCase());

  for (const field of datasetFields) {
    if (!presentHeaders.includes(field.field_name.toLowerCase())) {
      throw new Error(`CSV is missing the configured column: ${field.field_name}`);
    }
  }

  const foundIssues = [];
  const uniqueValuesMap = new Map(); // ruleId -> Set<string>

  let rowNumber = 1;
  for (const record of records) {
    for (const rule of activeRules) {
      const field = datasetFields.find((f) => f.field_id === rule.field_id);
      if (!field) continue;

      // Find matching record key case-insensitively
      const recordKey = Object.keys(record).find((k) => k.toLowerCase() === field.field_name.toLowerCase());
      const rawValue = recordKey ? record[recordKey] : '';
      const value = rawValue !== undefined && rawValue !== null ? String(rawValue).trim() : '';

      const failure = evaluateRule(rule, field, value, uniqueValuesMap);
      if (failure) {
        foundIssues.push({
          ruleId: rule.rule_id,
          fieldId: field.field_id,
          fieldName: field.field_name,
          rowNumber,
          severity: rule.severity,
          message: failure,
          observedValue: value || null,
        });
      }
    }
    rowNumber++;
  }

  return {
    totalRows: records.length,
    foundIssues,
  };
}

function evaluateRule(rule, field, value, uniqueValuesMap) {
  const isBlank = value === '';

  switch (rule.rule_type) {
    case 'REQUIRED':
      return isBlank ? 'A value is required.' : null;

    case 'UNIQUE': {
      if (isBlank) return null;
      if (!uniqueValuesMap.has(rule.rule_id)) {
        uniqueValuesMap.set(rule.rule_id, new Set());
      }
      const set = uniqueValuesMap.get(rule.rule_id);
      const normalized = value.toLowerCase();
      if (set.has(normalized)) {
        return 'This value duplicates an earlier row.';
      }
      set.add(normalized);
      return null;
    }

    case 'EMAIL':
      if (isBlank) return null;
      return EMAIL_REGEX.test(value) ? null : 'Enter a valid email address.';

    case 'RANGE': {
      if (isBlank) return null;
      const num = Number(value);
      if (isNaN(num)) return 'Value must be a number within the configured range.';
      const min = rule.rule_config?.min !== undefined ? Number(rule.rule_config.min) : -Infinity;
      const max = rule.rule_config?.max !== undefined ? Number(rule.rule_config.max) : Infinity;
      if (num < min || num > max) {
        return `Value must be between ${min} and ${max}.`;
      }
      return null;
    }

    case 'TYPE':
      return checkTypeValidity(field.data_type, value);

    default:
      return null;
  }
}

function checkTypeValidity(dataType, value) {
  if (value === '') return null;

  switch (dataType) {
    case 'TEXT':
      return null;
    case 'INTEGER':
      return /^[+-]?\d+$/.test(value) ? null : 'Value is not a valid integer.';
    case 'DECIMAL':
      return !isNaN(Number(value)) ? null : 'Value is not a valid decimal.';
    case 'DATE':
      return !isNaN(Date.parse(value)) ? null : 'Value is not a valid date.';
    case 'BOOLEAN':
      return ['true', 'false', '1', '0'].includes(value.toLowerCase()) ? null : 'Value is not a valid boolean.';
    default:
      return null;
  }
}

const API_BASE = import.meta.env.VITE_API_URL || '/api';

async function request(path, { token, ...options } = {}) {
  const headers = new Headers(options.headers || {});
  if (token) headers.set('Authorization', `Bearer ${token}`);
  if (!(options.body instanceof FormData) && options.body !== undefined) {
    headers.set('Content-Type', 'application/json');
  }

  const response = await fetch(`${API_BASE}${path}`, { ...options, headers });
  if (response.status === 204) return null;
  const contentType = response.headers.get('content-type') || '';
  const payload = contentType.includes('application/json') ? await response.json() : await response.text();
  if (!response.ok) {
    const message = typeof payload === 'object' && payload?.message
      ? payload.message
      : `Request failed (${response.status}).`;
    const error = new Error(message);
    error.status = response.status;
    error.code = payload?.code;
    throw error;
  }
  return payload;
}

function BakyaDatasetWorkspace({ token, initialDataset, onClose, onReload, onSelectRun }) {
  const [dataset, setDataset] = useState(initialDataset);
  const [fieldName, setFieldName] = useState('');
  const [dataType, setDataType] = useState('TEXT');
  const [fieldRule, setFieldRule] = useState({});
  const [newRuleType, setNewRuleType] = useState('REQUIRED');
  const [editName, setEditName] = useState(initialDataset.datasetName);
  const [editDescription, setEditDescription] = useState(initialDataset.description || '');
  const [ruleFieldId, setRuleFieldId] = useState(null);
  const [runResult, setRunResult] = useState(null);
  const [message, setMessage] = useState('');
  const [error, setError] = useState('');
  const [saving, setSaving] = useState(false);

  useEffect(() => {
    bakyaApi.dataset(token, initialDataset.datasetId).then((fresh) => {
      setDataset(fresh); setEditName(fresh.datasetName); setEditDescription(fresh.description || '');
    }).catch((err) => setError(err.message));
  }, [token, initialDataset.datasetId]);

  async function submitField(event) {
    event.preventDefault();
    setSaving(true); setError(''); setMessage('');
    try {
      const created = await bakyaApi.addField(token, dataset.datasetId, { fieldName, dataType });
      const ruleType = fieldRule.type;
      if (ruleType) {
        const ruleConfig = ruleType === 'RANGE' ? { min: Number(fieldRule.min), max: Number(fieldRule.max) } : {};
        await bakyaApi.addRule(token, created.fieldId, { ruleType, severity: fieldRule.severity || 'MEDIUM', ruleConfig });
      }
      setFieldName(''); setFieldRule({});
      await refreshDataset();
      setMessage('Field saved.');
    } catch (err) { setError(err.message); }
    finally { setSaving(false); }
  }

  async function saveDataset(event) {
    event.preventDefault(); setSaving(true); setError(''); setMessage('');
    try {
      await bakyaApi.updateDataset(token, dataset.datasetId, { datasetName: editName, description: editDescription });
      await refreshDataset(); await onReload(); setMessage('Dataset details updated.');
    } catch (err) { setError(err.message); }
    finally { setSaving(false); }
  }

  async function renameField(field) {
    const fieldName = window.prompt('Field name', field.fieldName);
    if (!fieldName?.trim() || fieldName.trim() === field.fieldName) return;
    try {
      await bakyaApi.updateField(token, field.fieldId, { fieldName: fieldName.trim(), dataType: field.dataType });
      await refreshDataset(); setMessage('Field updated.');
    } catch (err) { setError(err.message); }
  }

  async function archiveField(field) {
    if (!window.confirm(`Archive field â€œ${field.fieldName}â€? Past validation history will be retained.`)) return;
    try { await bakyaApi.archiveField(token, field.fieldId); await refreshDataset(); setMessage('Field archived.'); }
    catch (err) { setError(err.message); }
  }

  async function addRuleToField(event) {
    event.preventDefault();
    const form = new FormData(event.currentTarget);
    const ruleType = form.get('ruleType');
    const ruleConfig = ruleType === 'RANGE' ? { min: Number(form.get('min')), max: Number(form.get('max')) } : {};
    try {
      await bakyaApi.addRule(token, ruleFieldId, { ruleType, severity: form.get('severity'), ruleConfig });
      setRuleFieldId(null); await refreshDataset(); setMessage('Rule added.');
    } catch (err) { setError(err.message); }
  }

  async function deactivateRule(rule) {
    if (!window.confirm(`Disable the ${rule.ruleType} rule? Existing run history will remain.`)) return;
    try { await bakyaApi.deactivateRule(token, rule.ruleId); await refreshDataset(); setMessage('Rule disabled.'); }
    catch (err) { setError(err.message); }
  }

  async function submitRun(event) {
    event.preventDefault();
    const file = event.currentTarget.elements.file.files[0];
    if (!file) { setError('Choose a CSV file first.'); return; }
    setSaving(true); setError(''); setMessage('');
    try {
      const result = await bakyaApi.createRun(token, dataset.datasetId, file);
      setRunResult(result);
      setMessage(`Run ${result.runId} completed with ${result.issueCount} issue(s).`);
      await onReload();
    } catch (err) { setError(err.message); }
    finally { setSaving(false); }
  }

  async function resolveIssue(issue, status) {
    const note = window.prompt(status === 'RESOLVED' ? 'Briefly describe the resolution:' : 'Why are you changing this issue?');
    if (!note?.trim()) return;
    try {
      await bakyaApi.updateIssue(token, issue.issueId, { status, note: note.trim() });
      const updated = await bakyaApi.run(token, issue.runId);
      setRunResult(updated);
      await onReload();
    } catch (err) { setError(err.message); }
  }

  async function refreshDataset() {
    const fresh = await bakyaApi.dataset(token, dataset.datasetId);
    setDataset(fresh); setEditName(fresh.datasetName); setEditDescription(fresh.description || '');
  }

  return (
    <div className="modal-backdrop" role="presentation" onMouseDown={(event) => { if (event.target === event.currentTarget) onClose(); }}>
      <section className="workspace-modal" role="dialog" aria-modal="true" aria-labelledby="dataset-title">
        <div className="panel-heading modal-title"><div><p className="eyebrow">DATASET WORKSPACE</p><h2 id="dataset-title">{dataset.datasetName}</h2><p className="muted">Configure fields, rules, and validation runs.</p></div><button className="icon-button" onClick={onClose} aria-label="Close dataset workspace">Ã—</button></div>
        {error && <div role="alert" className="notice notice-error">{error}</div>}{message && <div className="notice notice-success">{message}</div>}
        <section className="sub-panel dataset-edit-panel"><div className="panel-heading"><div><h3>Dataset details</h3><p className="muted">Edit the name or description.</p></div></div><form className="inline-form" onSubmit={saveDataset}><label>Dataset name<input required maxLength="160" value={editName} onChange={(event) => setEditName(event.target.value)} /></label><label>Description<input maxLength="2000" value={editDescription} onChange={(event) => setEditDescription(event.target.value)} /></label><button className="button button-quiet" disabled={saving}>Save</button></form></section>
        <div className="workspace-grid">
          <section className="sub-panel"><div className="panel-heading"><div><h3>Fields & rules</h3><p className="muted">Rules run against each uploaded row.</p></div></div>
            {!dataset.fields?.length ? <p className="small-note">Add fields that match the CSV header names.</p> : <div className="field-list">{dataset.fields.map((field) => <article className="field-card" key={field.fieldId}>
              <div><strong>{field.fieldName}</strong><span className="type-label">{field.dataType}</span><span className={`status-pill ${field.active ? 'status-active' : 'status-archived'}`}>{field.active ? 'ACTIVE' : 'ARCHIVED'}</span></div>
              {field.rules?.filter((rule) => rule.active).length > 0 && <ul>{field.rules.filter((rule) => rule.active).map((rule) => <li key={rule.ruleId}>{rule.ruleType}{rule.ruleType === 'RANGE' ? ` ${rule.ruleConfig?.min}â€“${rule.ruleConfig?.max}` : ''}<span>{rule.severity.toLowerCase()}</span><button className="text-button danger-text" type="button" onClick={() => deactivateRule(rule)}>Disable</button></li>)}</ul>}
              {field.active && <div className="field-actions"><button className="text-button" type="button" onClick={() => renameField(field)}>Rename</button><button className="text-button" type="button" onClick={() => setRuleFieldId(ruleFieldId === field.fieldId ? null : field.fieldId)}>Add rule</button><button className="text-button danger-text" type="button" onClick={() => archiveField(field)}>Archive field</button></div>}
              {ruleFieldId === field.fieldId && <form className="form-stack compact-form" onSubmit={addRuleToField}><label>Rule<select name="ruleType" value={newRuleType} onChange={(event) => setNewRuleType(event.target.value)}><option value="REQUIRED">Required</option><option value="UNIQUE">Unique</option><option value="EMAIL">Email format</option><option value="RANGE">Number range</option><option value="TYPE">Field data type</option></select></label>{newRuleType === 'RANGE' && <div className="two-inputs"><label>Minimum<input name="min" type="number" step="any" required /></label><label>Maximum<input name="max" type="number" step="any" required /></label></div>}<label>Severity<select name="severity"><option>MEDIUM</option><option>LOW</option><option>HIGH</option></select></label><button className="button button-quiet">Save rule</button></form>}
            </article>)}</div>}
            <form className="form-stack compact-form" onSubmit={submitField}>
              <label>Field name<input required maxLength="120" value={fieldName} onChange={(event) => setFieldName(event.target.value)} placeholder="e.g. attendance_pct" /></label>
              <label>Data type<select value={dataType} onChange={(event) => setDataType(event.target.value)}><option>TEXT</option><option>INTEGER</option><option>DECIMAL</option><option>DATE</option><option>BOOLEAN</option></select></label>
              <label>Validation rule<select value={fieldRule.type || ''} onChange={(event) => setFieldRule({ type: event.target.value, severity: 'MEDIUM' })}><option value="">No initial rule</option><option value="REQUIRED">Required</option><option value="UNIQUE">Unique</option><option value="EMAIL">Email format</option><option value="RANGE">Number range</option><option value="TYPE">Field data type</option></select></label>

package com.datapulse.security;

import com.nimbusds.jose.jwk.source.ImmutableSecret;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwtDecoder;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;
import org.springframework.security.oauth2.jwt.NimbusJwtEncoder;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter;
import org.springframework.security.oauth2.server.resource.authentication.JwtGrantedAuthoritiesConverter;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.CorsConfigurationSource;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;

import javax.crypto.SecretKey;
import javax.crypto.spec.SecretKeySpec;
import java.util.Base64;
import java.util.List;

@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {
    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(12);
    }

    @Bean
    SecretKey jwtSecretKey(@Value("${datapulse.jwt.secret-base64}") String secretBase64) {
        if (secretBase64 == null || secretBase64.isBlank()) {
            throw new IllegalStateException("DATAPULSE_JWT_SECRET_BASE64 must be set; generate one with openssl rand -base64 32");
        }
        byte[] keyBytes;
        try {
            keyBytes = Base64.getDecoder().decode(secretBase64.trim());
        } catch (IllegalArgumentException ex) {
            throw new IllegalStateException("DATAPULSE_JWT_SECRET_BASE64 must be valid Base64", ex);
        }
        if (keyBytes.length < 32) {
            throw new IllegalStateException("JWT HMAC secret must decode to at least 32 bytes");
        }
        return new SecretKeySpec(keyBytes, "HmacSHA256");
    }

    @Bean
    JwtEncoder jwtEncoder(SecretKey jwtSecretKey) {
        return new NimbusJwtEncoder(new ImmutableSecret<>(jwtSecretKey));
    }

    @Bean
    JwtDecoder jwtDecoder(SecretKey jwtSecretKey) {
        return NimbusJwtDecoder.withSecretKey(jwtSecretKey).macAlgorithm(MacAlgorithm.HS256).build();
    }

    @Bean
    JwtAuthenticationConverter jwtAuthenticationConverter() {
        JwtGrantedAuthoritiesConverter authorities = new JwtGrantedAuthoritiesConverter();
        authorities.setAuthoritiesClaimName("roles");
        authorities.setAuthorityPrefix("");
        JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(authorities);
        return converter;
    }

    @Bean
    SecurityFilterChain securityFilterChain(HttpSecurity http,
                                             JwtAuthenticationConverter jwtAuthenticationConverter,
                                             CorsConfigurationSource corsConfigurationSource) throws Exception {
        return http
                .csrf(csrf -> csrf.disable())
                .cors(cors -> cors.configurationSource(corsConfigurationSource))
                .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers("/api/auth/login", "/api/health").permitAll()
                        .anyRequest().authenticated())
                .oauth2ResourceServer(oauth -> oauth.jwt(jwt -> jwt.jwtAuthenticationConverter(jwtAuthenticationConverter)))
                .build();
    }

    @Bean
    CorsConfigurationSource corsConfigurationSource(@Value("${datapulse.cors.origin}") String origin) {
        CorsConfiguration configuration = new CorsConfiguration();

package com.datapulse.service;

import com.datapulse.api.ApiDtos;

import com.datapulse.repository.ValidationRuleRepository;
import com.datapulse.repository.ValidationRunRepository;
import jakarta.persistence.EntityManager;
import org.apache.commons.csv.CSVFormat;
import org.apache.commons.csv.CSVParser;
import org.apache.commons.csv.CSVRecord;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;

import java.time.LocalDate;

import java.util.*;

@Service
public class CsvValidationService {
    private static final long MAX_BYTES = 5L * 1024 * 1024;
    private static final int MAX_ROWS = 5000;
    private static final Pattern EMAIL = Pattern.compile("^[A-Z0-9._%+-]+@[A-Z0-9.-]+\\.[A-Z]{2,}$", Pattern.CASE_INSENSITIVE);

    private final DatasetService datasetService;
    private final DatasetFieldRepository fields;
    private final ValidationRuleRepository rules;
    private final ValidationRunRepository runs;
    private final QualityIssueRepository issues;
    private final QualityScoreRepository scores;
    private final JdbcTemplate jdbcTemplate;
    private final EntityManager entityManager;
    private final RunQueryService runQueryService;

    public CsvValidationService(DatasetService datasetService, DatasetFieldRepository fields,
                                ValidationRuleRepository rules, ValidationRunRepository runs,
                                QualityIssueRepository issues, QualityScoreRepository scores,
                                JdbcTemplate jdbcTemplate, EntityManager entityManager,
                                RunQueryService runQueryService) {
        this.datasetService = datasetService;
        this.fields = fields;
        this.rules = rules;
        this.runs = runs;
        this.issues = issues;
        this.scores = scores;
        this.jdbcTemplate = jdbcTemplate;
        this.entityManager = entityManager;
        this.runQueryService = runQueryService;
    }

    @Transactional
    public ApiDtos.RunView run(long datasetId, long userId, boolean admin, MultipartFile file) {
        if (file == null || file.isEmpty()) throw ApiException.badRequest("Choose a CSV file to run validation.");
        if (file.getSize() > MAX_BYTES) throw ApiException.badRequest("CSV files must be 5 MB or smaller.");
        String filename = file.getOriginalFilename();
        if (filename == null || !filename.toLowerCase(Locale.ROOT).endsWith(".csv")) {
            throw ApiException.badRequest("Upload a file with the .csv extension.");
        }

        DatasetEntity dataset = datasetService.accessibleDataset(datasetId, userId, admin);
        if (!"ACTIVE".equals(dataset.getStatus())) {
            throw ApiException.badRequest("Archived datasets cannot start new validation runs.");
        }
        List<DatasetFieldEntity> datasetFields = fields.findAllByDataset_DatasetIdAndActiveTrueOrderByFieldIdAsc(datasetId);
        if (datasetFields.isEmpty()) throw ApiException.badRequest("Add at least one dataset field before running validation.");
        List<ValidationRuleEntity> activeRules = rules.findAllByField_Dataset_DatasetIdAndField_ActiveTrueAndActiveTrueOrderByRuleIdAsc(datasetId);
        if (activeRules.isEmpty()) throw ApiException.badRequest("Add at least one active validation rule before running validation.");

        ValidationRunEntity run = new ValidationRunEntity();
        run.setDataset(dataset);
        run.setStartedBy(dataset.getOwner().getUserId().equals(userId) ? dataset.getOwner() : findUser(userId));
        run.setStatus("RUNNING");
        run.setTotalRows(0);
        run.setIssueCount(0);
        run = runs.saveAndFlush(run);

        final ValidationRunEntity currentRun = run;
        setAuditActor(userId);
        List<QualityIssueEntity> foundIssues = new ArrayList<>();
        int rowCount;
        try (InputStreamReader reader = new InputStreamReader(file.getInputStream(), StandardCharsets.UTF_8);
             CSVParser parser = CSVFormat.DEFAULT.builder()
                     .setHeader()
                     .setSkipHeaderRecord(true)
                     .setIgnoreEmptyLines(true)
                     .setTrim(false)
                     .get()
                     .parse(reader)) {
            Map<String, String> headers = normalizedHeaders(parser.getHeaderMap().keySet());
            for (DatasetFieldEntity field : datasetFields) {
                String header = headers.get(field.getFieldName().toLowerCase(Locale.ROOT));
                if (header == null) throw ApiException.badRequest("CSV is missing the configured column: " + field.getFieldName());
            }
            Map<Long, Set<String>> uniqueValues = new HashMap<>();
            rowCount = 0;
            for (CSVRecord record : parser) {
                rowCount++;
                if (rowCount > MAX_ROWS) throw ApiException.badRequest("CSV files are limited to 5,000 data rows for this project demo.");
                for (ValidationRuleEntity rule : activeRules) {
                    DatasetFieldEntity field = rule.getField();
                    String header = headers.get(field.getFieldName().toLowerCase(Locale.ROOT));
                    String value = header != null && record.isMapped(header) && record.isSet(header) ? record.get(header).trim() : "";
                    String failure = failureMessage(rule, value, uniqueValues);
                    if (failure != null) {
                        QualityIssueEntity issue = new QualityIssueEntity();
                        issue.setRun(currentRun);
                        issue.setRule(rule);
                        issue.setRowNumber((int) record.getRecordNumber());
                        issue.setSeverity(rule.getSeverity());
                        issue.setMessage(failure);
                        issue.setObservedValue(value.isBlank() ? null : value);
                        foundIssues.add(issue);
                    }
                }
            }
        } catch (IOException | IllegalStateException ex) {
            throw ApiException.badRequest("Could not read the CSV. Check that it has one header row and valid CSV formatting.");
        }

        if (!foundIssues.isEmpty()) issues.saveAll(foundIssues);
        currentRun.setTotalRows(rowCount);
        currentRun.setIssueCount(foundIssues.size());
        currentRun.setStatus("COMPLETED");
        currentRun.setCompletedAt(OffsetDateTime.now());
        runs.save(currentRun);
        entityManager.flush();
        jdbcTemplate.update("CALL recalculate_quality_score(?)", currentRun.getRunId());
        entityManager.clear();
        return runQueryService.get(currentRun.getRunId(), userId, admin);
    }

    private com.datapulse.domain.UserEntity findUser(long userId) {
        return entityManager.getReference(com.datapulse.domain.UserEntity.class, userId);
    }

    private void setAuditActor(long userId) {
        jdbcTemplate.queryForObject("select set_config('app.user_id', ?, true)", String.class, Long.toString(userId));
    }

    private Map<String, String> normalizedHeaders(Set<String> rawHeaders) {
        if (rawHeaders == null || rawHeaders.isEmpty()) throw ApiException.badRequest("CSV must contain a header row.");
        Map<String, String> normalized = new HashMap<>();
        for (String header : rawHeaders) {
            if (header == null || header.isBlank()) throw ApiException.badRequest("CSV headers cannot be blank.");
            String key = header.trim().toLowerCase(Locale.ROOT);
            if (normalized.putIfAbsent(key, header) != null) throw ApiException.badRequest("CSV headers must be unique, ignoring case.");
        }
        return normalized;
    }

    private String failureMessage(ValidationRuleEntity rule, String value, Map<Long, Set<String>> uniqueValues) {
        return switch (rule.getRuleType()) {
            case "REQUIRED" -> value.isBlank() ? "A value is required." : null;
            case "UNIQUE" -> {
                if (value.isBlank()) yield null;
                Set<String> seen = uniqueValues.computeIfAbsent(rule.getRuleId(), ignored -> new HashSet<>());
                yield seen.add(value.toLowerCase(Locale.ROOT)) ? null : "This value duplicates an earlier row.";
            }
            case "EMAIL" -> value.isBlank() || EMAIL.matcher(value).matches() ? null : "Enter a valid email address.";
            case "RANGE" -> rangeFailure(rule, value);
            case "TYPE" -> typeFailure(rule.getField().getDataType(), value);
            default -> "This rule type is not supported by the validation engine.";
        };
    }

    private String typeFailure(String dataType, String value) {
        if (value.isBlank()) return null;
        boolean valid;
        try {
            valid = switch (dataType) {
                case "TEXT" -> true;
                case "INTEGER" -> value.matches("[+-]?\\d+");
                case "DECIMAL" -> { new BigDecimal(value); yield true; }
                case "DATE" -> { LocalDate.parse(value); yield true; }
                case "BOOLEAN" -> value.equalsIgnoreCase("true") || value.equalsIgnoreCase("false");
                default -> false;
            };
        } catch (RuntimeException ex) {
            valid = false;
        }
        return valid ? null : "Value is not a valid " + dataType.toLowerCase(Locale.ROOT) + ".";
    }

    private String rangeFailure(ValidationRuleEntity rule, String value) {
        if (value.isBlank()) return null;
        try {
            BigDecimal actual = new BigDecimal(value);
            BigDecimal min = new BigDecimal(rule.getRuleConfig().get("min").toString());
            BigDecimal max = new BigDecimal(rule.getRuleConfig().get("max").toString());
            return actual.compareTo(min) < 0 || actual.compareTo(max) > 0
                    ? "Value must be between " + min.stripTrailingZeros().toPlainString() + " and " + max.stripTrailingZeros().toPlainString() + "."
                    : null;
        } catch (RuntimeException ex) {
            return "Value must be a number within the configured range.";
        }
    }
}

University departments exchange spreadsheets for routine work, but missing values, malformed entries, duplicate identifiers, and out-of-range measurements are often discovered late. # DataPulse Entity Relationship Design

DataPulse is scoped for a small, demonstrable institutional dataset workflow. An analyst registers a dataset and its fields, attaches validation rules, uploads a CSV for a run, reviews the resulting issues, and records resolution history. The CSV is processed by the backend for the run; the first version stores dataset metadata and results rather than arbitrary source rows.


## Design decisions

- There are ten tables. `Users` is the only account table; `Roles` stores role names and `Users.role_id` assigns a role. There are no separate Admin or Analyst account tables.
- Each table has a primary key. Foreign keys express ownership and history. Dataset/field/rule/run relationships are represented once; `Quality_Scores` references a run and does not duplicate its dataset ID.
- A quality issue references the validation rule that failed. Its field is obtained through `Validation_Rules.field_id`, avoiding another copy of the same relationship.
- Requiredness is represented by an active `REQUIRED` validation rule rather than duplicated as a second flag on `Dataset_Fields`.
- `Quality_Issues` also stores the CSV data-row number (header excluded), observed value, severity snapshot, message, and current status.
- The backend must verify that each run and its rules belong to the same dataset before writing results. This cross-table rule is enforced in the transactional service.
- Dataset deletion is restricted once history exists. Fields and rules are soft-archived with `is_active = false`, preserving run history and issue foreign keys.

## Cardinalities

- One role can be assigned to many users; each user has one role.
- One dataset has many fields and validation runs.
- One field can have many validation rules.
- One validation run can produce many issues; each issue is tied to one run and one rule.
- One issue can have multiple resolution-history entries.
- A completed run has at most one score record.

## Relational schema and 3NF notes

The complete relational schema is in `rudra/db/schema.sql`; the column-by-column definitions are in `rudra/docs/DATA_DICTIONARY.md`. The ten base tables are ROLES, USERS, DATASETS, DATASET_FIELDS, VALIDATION_RULES, VALIDATION_RUNS, QUALITY_ISSUES, ISSUE_RESOLUTIONS, QUALITY_SCORES, and AUDIT_LOGS. Primary and foreign keys in the ER diagram match the DDL.

The design targets Third Normal Form. Each table stores one kind of entity or event, each non-key column describes that table's key, and no non-key column is included to carry a transitive dependency from another table. Role names are stored once and referenced by USERS; datasets are referenced by fields and runs; issues reference a validation rule rather than duplicating its field; scores reference a run rather than duplicating its dataset; resolution history is kept in its own table. Severity and message on an issue are intentional run-time snapshots so later rule edits do not rewrite historical outcomes.

Integrity rules include primary/foreign keys, non-null columns, unique lowercased user email, per-owner dataset-name uniqueness, per-dataset field-name uniqueness, check constraints for statuses/rule types/scores, defaults for lifecycle columns, and indexes for common joins and filters. The backend uses ORM-based parameter binding for routine operations; raw SQL is limited to the dashboard's view/aggregate and invocation of the stored procedure.

# DataPulse API Contract

Backend: Spring Boot REST API. Frontend: React in `bakya/frontend/`. Use JSON for API bodies except the CSV run upload. Unless stated otherwise, all endpoints are under `/api` and require a bearer JWT after login.

## Authentication

| Method and path | Request | Response / behavior |
|---|---|---|
| `POST /auth/login` | `{ "email": "...", "password": "..." }` | `{ "token": "...", "user": { "userId": 1, "fullName": "...", "email": "...", "role": "ANALYST" } }` |
| `GET /auth/me` | Bearer token | Returns the authenticated user's safe profile and role. |
| `POST /auth/logout` | Bearer token | Stateless JWT clients clear the token; backend may revoke it if a denylist is implemented. |

Never return `password_hash` from an endpoint. Seed development users with BCrypt hashes and document their local-only setup without committing secrets.

## Main resources

| Method and path | Purpose |
|---|---|
| `GET /datasets?page=&size=&q=&status=` | List the user's permitted datasets with pagination and filters. Admin may view all. |
| `POST /datasets` | Create a dataset. Owner is taken from the authenticated user, not trusted from the request body. |
| `GET /datasets/{datasetId}` | Dataset details including fields and rules. |
| `PUT /datasets/{datasetId}` | Update dataset metadata. |
| `DELETE /datasets/{datasetId}` | Archive the dataset; preserve historical runs. |
| `POST /datasets/{datasetId}/fields` | Add a field with `fieldName` and `dataType`; requiredness is a `REQUIRED` validation rule. |
| `PUT /fields/{fieldId}` / `DELETE /fields/{fieldId}` | Update a field or disable it if it has history. |
| `POST /fields/{fieldId}/rules` | Add a rule with `ruleType`, `severity`, and `ruleConfig`. Types: `REQUIRED`, `UNIQUE`, `EMAIL`, `RANGE`, `TYPE`; `TYPE` checks the field's configured data type. |
| `PUT /rules/{ruleId}` / `DELETE /rules/{ruleId}` | Update or deactivate a rule. |
| `POST /datasets/{datasetId}/runs` | Multipart upload with part name `file`; validate CSV columns against dataset fields and persist run/issues/score in one transaction. |
| `GET /runs/{runId}` | Run status, counts, score, and paginated issues. |
| `PATCH /issues/{issueId}/status` | `{ "status": "RESOLVED", "note": "..." }`; append an `Issue_Resolutions` history row. |
| `GET /dashboard/summary` | Summary counts and latest quality scores using the database view/query. |
| `GET /admin/overview` | Admin-only workspace overview across every dataset; an Analyst receives HTTP 403. |

## Roles and error shape

- `ADMIN`: view and manage all datasets; access the admin overview.
- `ANALYST`: manage owned datasets, fields, rules, runs, and issue resolutions.
- Enforce ownership and roles on the API, not only by hiding frontend buttons.
- Return standard HTTP statuses and a consistent error body, for example `{ "code": "VALIDATION_ERROR", "message": "...", "details": [] }`.
- Validate page sizes, CSV headers, rule configuration, and all user-provided IDs. Never build SQL by concatenating user input.

## End-to-end acceptance workflow

1. Log in as an Analyst and create a dataset with fields `record_id`, `email`, `attendance_pct`, and `department`.
2. Add rules: `record_id` unique and required, `email` required and email-formatted, `attendance_pct` in the range 0 to 100.
3. Upload `rudra/db/sample_validation.csv` to start a run.
4. See the run summary, issues, and score; resolve at least one issue and see the updated status/history.
5. Log in as Admin and verify the admin-only page/API behavior.
